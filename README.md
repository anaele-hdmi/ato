# 跡

スマホのブラウザだけで完結する、定点の丘の時間を指で見て回る作品。

## 起動

```
npm install
npm run dev      # http://localhost:5173 （同一LANのスマホからは表示される Network URL）
npm run build    # dist/ に静的ファイル
```

## 操作
- 1本指ドラッグ: 回る（慣性あり） / ピンチ: 寄る・引く / 2本指ドラッグ: 見る場所をずらす（家の場所へゆっくり戻る）
- 下のバー: 時間。指をバーから上に離しながら動かすと微調整
- 右下: 速度（停止・遅・中・速）とミュート
- デスクトップ: 左ドラッグ=回る、右ドラッグ/Shift+ドラッグ=ずらす、ホイール=寄る・引く、←→=時間、Space=速度
- 最初のタップで音が出る

## 今何ができるか（Phase 0）
- 全画面キャンバス、オービット／ピンチ／2本指パン（ジェスチャは最初の動きで確定）
- ハイトマップの丘（頂点シェーダ変位）、空、太陽（季節と時刻で動く）、高さ依存の霧と朝靄
- 原点に白い小さな家（石の基礎・煙突・冬の朝の煙）、井戸、石垣、リンゴの木
- 被写界深度（寄ると前景の草が溶ける、引くとチルトシフト寄りのミニチュア感）、薄いグレイン、軽い色収差
- スクラブで季節が回る（年は表示しない。速く動かすと季節は中立へ寄る）。昼夜は約4分で一巡
- 顔のない人物が数人、ゆっくり歩く／立ち止まる
- 音: 最初のタップで解錠。風・草・遠い鳥・朝の帯域（すべて手続き生成の仮音）。高度で高域が落ちる。スクラブを速く動かすと音が引き伸びる
- 影（太陽の正射影シャドウ）、熱で重いときはDPRを1.25まで自動で下げる
