# 跡

スマホのブラウザだけで完結する、定点の丘の時間を指で見て回る作品。

## 起動

```
npm install
npm run dev      # http://localhost:5173 （同一LANのスマホからは表示される Network URL）
npm run build    # dist/ に静的ファイル
```

## 操作
- 1本指ドラッグ: 回る（慣性あり） / ピンチ: 寄る・引く / 2本指ドラッグ: 見る場所をずらす（家の場所へゆっくり戻る）
- 下のバー: 時間。指をバーから上に離しながら動かすと微調整。バーの上の細い線は「家があった年月」を全体の時間に対する縮尺で表し、時間が進むほど髪の毛1本分まで細くなる
- 右下: 速度（停止・遅・中・速）とミュート。遅では日が1〜2秒で空を渡り、速くなるほど昼夜が長時間露光のような平均の光に溶け、太陽は空の光の帯になる
- デスクトップ: 左ドラッグ=回る、右ドラッグ/Shift+ドラッグ=ずらす、ホイール=寄る・引く、←→=時間、Space=速度
- 最初のタップで音が出る

## 今何ができるか（Phase 4 まで＋磨き込み1回目）
- 全画面キャンバス、オービット／ピンチ／2本指パン（ジェスチャは最初の動きで確定）。カメラは建物の中に入らない（入る位置なら手前に寄る）
- ハイトマップの丘（頂点シェーダ変位）、空、太陽（季節と時刻で動く）、高さ依存の霧と朝靄
- 原点に白い小さな家（石の基礎・煙突・冬の朝の煙）、井戸、石垣、リンゴの木（春に花、秋に実）
- 被写界深度（寄ると前景の草が溶ける、引くとチルトシフト寄りのミニチュア感）、薄いグレイン、軽い色収差
- スクラブで季節が回る（年は表示しない）。昼夜は約4分で一巡
- 時間とともに: 轍 → 砂利道 → 舗装 → 拡幅（歩道・並木）。隣家が生え、畑が広がり、電柱と電線が立ち、道沿いに小さな商店（読めない看板）
- 市街地が遠くから近づき、格子状の街路・中層ブロック → 高層 → 一部が過度に巨大化。夜は窓の灯、街灯、航空障害灯、看板の光、空の光害
- 元の家は高層に囲まれた後に消え、基礎石・井戸・石列が残る。都市の最盛期もその正方形だけ建物が建たず、夜はそこだけ暗い
- 人物: 村の時代は顔のない数人。都市の時代は歩道を埋める顔のない群衆（寄ると人、引くと路上の点と車のライト）
- 音: 最初のタップで解錠。風・草・鳥 → 砂利の足音・遠い作業音・牛 → 電線の唸り → 遠い交通・靴音・扉 → 都市の低いドローン・光害の薄い高域。
  すべて手続き生成の仮音で、時間に応じてクロスフェード。高度で高域が落ちる。スクラブを速く動かすと音が引き伸びる
- 影（太陽の正射影シャドウ）、熱で重いときはDPRを1.25まで自動で下げる
- 混乱期: まずコントラストだけが壊れ、窓の灯が地区ごとに偏り、街灯が明滅し、遠くに数本の煙柱。事件は描かない
- 衰退: 窓が割れ、建物に穴が開き、上端がぎざぎざに欠けながら低い瓦礫へ崩れる。舗装の割れ目から草、壁を這う緑、瓦礫の間から木
- 痕跡: 基礎石が一つずつ減り、石列と不自然にまっすぐな微高地だけになり、やがて何もなくなる
- 音: 混乱期は音を増やさず穴を開ける（沈黙の区間、遠い金属音）。衰退でドローンが枯れ、虫と風、建物のきしみが戻る。無人の時代は雨と動物
- 深時間: スクラブ後半は対数。森 → 一度きりの氷期 → 乾いた時代（大地が削られ形を変える）→ 海が来て戻らない。季節は消え、気候だけが一方向に変わる
- 終端（スクラブの右端付近で成立、選択UIなし、同時に成立しうる）
  - 海進のあと、家の場所は浅い海の底。ゆっくりした潮の満ち引きで、丘が現れては沈む
  - 無操作: 数秒でスクラブとボタンが消え、光と大気だけになる（触れると戻る）
  - 終端を数秒保つと、中央やや下に作品名が小さくフェードインし、さらに薄くなる。スクラブを戻すと即消える
