# ato

ミクロな世界と長い時間をあつかうシミュレーション作品。

| 作品 | 内容 |
|---|---|
| `kaeru/` 還る部屋 | 1926年から閉ざされた部屋に、実際の太陽の光と水と時間が植物を呼び戻していく。窓を開け、水をこぼし、椅子を動かす |
| `dust-floor/` 塵の床 | 東京の実際の太陽の位置で光が差し込む、100年分の塵が積もった床 |

## GitHub Pages で公開する

1. 作品ファイルを編集したら、Pages 用のファイルを書き出す

   ```sh
   python3 tools/build_pages.py
   ```

   `kaeru/index.html` などを doctype とスマホ用 viewport で包み、`docs/` に出力する。

2. リポジトリの **Settings → Pages** で次のように設定する
   - Source: **Deploy from a branch**
   - Branch: 公開したいブランチ（例：`main`）、フォルダは **`/docs`**

3. 数分後に `https://<ユーザー名>.github.io/ato/` で公開される。
   - 作品一覧：`/ato/`
   - 還る部屋：`/ato/kaeru/`

## 進捗の保存

- GitHub Pages 上では、部屋の状態は**各自のブラウザ（localStorage）**に保存される。1人ずつ別の部屋になり、閉じている間も部屋の時間は進む（現実の1日＝部屋の1年）。
- 同じ人でも、別の端末や別のブラウザでは別の部屋になる。
- ブラウザのサイトデータを消すと部屋も消える。
- Claude のアーティファクトとして開いた場合は、アカウントごとの保存領域に保存される。

## 操作（還る部屋）

| 操作 | スマホ | パソコン |
|---|---|---|
| 見回す | 1本指でドラッグ | ドラッグ／←→ |
| 前後に歩く | ピンチ | ホイール／↑↓・W S |
| 元の視点に戻る | ダブルタップ | ダブルクリック |
| 水をこぼす | 「水をこぼす」を選んで床をタップ | 同左（クリック） |
| 椅子を動かす | 「椅子を動かす」を選んで椅子をドラッグ | 同左 |
