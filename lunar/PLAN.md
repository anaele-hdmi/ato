# ツキノワ — 月往還シミュレータ 計画

## 決定事項
| 項目 | 決定 |
|---|---|
| 中心の遊び | 各段階の**主噴射は1回**。予測線を見ながら決める。巡航中の小さな修正噴射のみ許可（★評価で減点） |
| 操作 | 2方式を切替可能にして比較する。A: 長押し＋スロー演出 / B: 引っ張って離す（Δvとタイミングを計画 → 自動実行） |
| 物理 | 実物理（地球＋月の重力、有限噴射、大気抵抗＋揚力）。数値表示は実値 |
| 表示スケール | デフォルメ。天体は実寸の3倍、距離はべき乗で圧縮（地球半径:月距離 = 1:9.5、実際は1:60）。月の近くは月中心の写像に滑らかに切替 |
| 公開 | まず Artifact。のちに GitHub Pages（`gh-pages` は「跡」のワークフローが上書きするため、配置方法は別途決める） |
| 音 | あり（Web Audio の手続き音：エンジン、環境音、UI、再突入、成功・失敗） |
| 置き場所 | `ato/lunar/`（「跡」とは独立） |

## 数値実験の結果（自動操縦、実物理）
| 段階 | Δv | 敏感さ |
|---|---|---|
| TLI | 約3.13 km/s | 5 m/s のずれで近月点が約1万km動く |
| LOI | 約0.6 km/s（近月点1,400 km → ほぼ円軌道） | 中 |
| TEI | 約0.83 km/s | 1 m/s で近地点が約120 km動く |
| 再突入 | 近地点 30〜60 km で着水 | 20 km以下は12G超、70 km以上はスキップ |

Δv予算は 5.5 km/s（必要量の合計 約4.6 km/s に余裕を加えた値）。

## 段階と目標帯
| # | 段階 | 主噴射 | 目標帯（予測値） |
|---|---|---|---|
| 1 | TLI | 順方向（地球基準） | 近月点高度 50〜3,000 km |
| 2 | 巡航 | ― | 同上を維持（修正のみ） |
| 3 | LOI | 逆方向（月基準） | 遠月点高度 50〜3,000 km、または近月点+2,500 km以内（ほぼ円軌道） |
| 4 | TEI | 順方向（月基準） | 地球の近地点高度 0〜2,000 km |
| 5 | 帰還・再突入 | ― | 近地点 30〜60 km（再突入回廊）、最大G 12未満 |

TEIの精度（1 m/sで近地点が約120 km動く）は指の操作では出ないため、実際の運用（巡航中の軌道修正）と同じく、帰還中の修正で回廊に合わせる設計にする。

## 補助
- 点火の窓マーカーとカウントダウン（TLI・TEIは解析解、LOIは予測した近月点）
- 重要な場面の手前で時間加速を自動で下げる
- モードA: 予測値が目標帯に近づくとスロー（色が抜け、音程も下がる）
- チェックポイント（段階の開始時）と、段階の選択（自動操縦で状態を生成）

## ★評価
主噴射の精度、修正に使ったΔv、再突入の最大G。

## 版
v0 遊びの検証（本版） → v1 光と空気感の仕上げ → v2 演出と音の作り込み、GitHub Pages への公開

## v0 の検証結果（ゲーム内ロジックを自動操作して確認）
- モードA: TLI → LOI → TEI → 修正噴射 → 再突入 → 着水まで成功（約10.2日、最大3.5G）
- モードB: TLI・LOI・TEI の計画値と実際の結果が一致（TEI計画の近地点105 km → 実際105 km）
- 段階選択用の状態は、同じ物理の自動操縦で起動時に生成
- 実機（スマホGPU）での描画速度は未検証。重い場合は解像度を自動で下げる
