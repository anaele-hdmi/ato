塵の床

床をなぞると、塵に跡が残ります。残せるのは一度だけです。

しくみ

1926年9月25日から誰も入っていない部屋、という設定です。窓から差す光の向き、床に積もった塵の量、跡が埋もれるまでの時間は、開いた時点の時刻から計算しています。訪れた人が残した跡は保存され、次に開いた人にも見えます。

項目値根拠
場所・窓35.68°N 139.77°E東京。南向きの窓、幅1.2m、床上0.8〜2.1m 設定
太陽実時刻低精度の太陽位置式（誤差0.1°程度の見込み）。高度が低いほど大気を長く通るため、光は赤くなる
月実時刻低精度の月位置式（誤差1°程度の見込み）。明るさは満ち欠けの割合に比例させている
夜の見え方露出補正月光は日光の数十万分の一なので、長時間露光のカメラで見たように明るさを上げている
描き方パストレーシング光線を1画素ずつ追跡し、壁や床での跳ね返り（3回まで）、窓を面光源とする空の光、太陽の視直径0.53°による影のぼけを計算。開いてから数秒かけて画が落ち着く
光の筋前方散乱塵の粒は光を進行方向へ強く散らす（ミー散乱）。窓の方を向いたときに筋がいちばん明るく見える
塵の沈降v = (ρ−ρair)gd²/18μストークスの式。直径10µmで約3mm/秒、1µmで約0.03mm/秒。宙を漂う動きの大半は空気の流れ
塵の堆積速度10 mg/m²/日仮定 室内の実測値は換気・人の出入り・場所で大きく変わる。要検証
床の見え方1 − e−m/6.7粒子がランダムに落ちるときの被覆率（ポアソン過程）。6.7 g/m²は直径10µmの粒が床を一層覆う量
跡が見えなくなる差 < 2%仮定 跡の内と外の被覆率の差が2%を下回った時点
指の跡幅 16mmなぞった部分の塵はすべて取り除かれるとみなす 仮定

光の筋の中に見える粒は、実際の大きさでは目に見えないため拡大して描いています。手前や奥がぼけて見えるのは、ピントを部屋の中ほど（約3.6m）に合わせたカメラを想定しているためです。椅子は物語上の設定です。天気は反映していません。
