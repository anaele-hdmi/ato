還る部屋

図鑑

この部屋に現れた生きものの記録です。条件がそろった場所に、自分でやって来ます。

しくみ

1926年9月25日から閉ざされた部屋です。あなたにできるのは、窓を開けること、水をこぼすこと、椅子を動かすことだけです。何が育つかは、光と水と時間が決めます。部屋はあなただけのもので、閉じている間も時間は進みます（現実の1日が部屋の1年）。

項目値根拠
場所・窓35.68°N 139.77°E東京。南向きの窓、幅1.2m、床上0.8〜2.1m 設定
夜の光街灯・都市の夜空窓の外に街灯がある 設定。月が窓から差す時間は月光になる。夜は露出を上げたカメラの見え方
太陽・月部屋の暦で計算低精度の位置式（太陽は誤差0.1°程度、月は1°程度の見込み）。光の筋の向きと、床のどこに日が当たるかはこの計算どおり
植物が受ける光半月ごとに計算床と壁の5〜10cm四方ごとに、30分おきの太陽の向きから直射が届くかを判定（椅子の影を含む）。空の光は窓を面光源として計算
時間×365 / ×86400 / ×604800現実の1日＝部屋の1年／1秒＝1日／1秒＝1週間
天気日ごとに抽選仮定 月ごとの雨の確率を簡略化して設定。実際の東京の記録ではない
成長の速さ・条件簡略モデル仮定 遷移の順序（藍藻→コケ→シダ）と、各種が好む光と水の傾向は実際の生態にもとづく。速さは遊べるように調整した値で、実測値ではない
光の筋パストレーシング空気中の塵による前方散乱を計算。部屋の湿り気が増えると筋が濃くなる
塵の沈降ストークスの式直径10µmで約3mm/秒。光の中に緑がかった粒が混ざるのは胞子

画面は開いてから数秒かけて落ち着きます。早回し中の光の筋が流れて見えるのは、長時間露光のように数日分の光が重なっているためです。
