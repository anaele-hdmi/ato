# HANEDA APPROACH — 設計書 v0.1

緑燐光のレーダー画面で、羽田の到着機を実在の STAR・経路点・滑走路に沿ってさばく ATC ゲーム（Endless ATC 系）。

## 1. 決定事項

| # | 論点 | 決定 |
|---|---|---|
| 1 | 役割 | 進入管制（東京アプローチ）のみ。到着機の順序付け・間隔設定・進入許可まで |
| 2 | 運用 | 北風運用（34L / 34R 着陸）のみ。南風（22/23）は第2段階 |
| 3 | 現実準拠 | 経路・高度制限・座標は AIP 準拠。機体性能は簡略モデル |
| 4 | 操作 | クリック操作 ＋ コマンド入力の併用 |
| 5 | 交通 | ランダム生成。流入方面の比率だけ現実寄せ |
| 6 | 勝敗 | 間隔違反で終了。スコア＝着陸機数 |
| 7 | 形式 | ブラウザで動く HTML（PC／スマホ） |

## 2. データ（実データ）

生成物: `data/rjtt_north.json`（再生成: `python tools/extract_rjtt.py`）

| 項目 | 出典 | 発効日 | 精度・検証 |
|---|---|---|---|
| STAR 20本（経路点列・真方位・距離・高度制限） | AIP Japan RJTT AD2.24 | 2024-10-31 | PDF の表を機械抽出 |
| 経路点座標 51点 | 始点4点（XAC/AKSEL/AROSA/POLIX）は AIP 記載値。他は AIP の方位・距離から推測航法で計算 | 同上 | 複数 STAR で同じ点に到達した場合の不一致は最大 0.085NM。終点 ARLON・KAIHO・UMUKI・CACAO は独立データ（opennav）と 0.01〜0.05NM で一致 |
| 滑走路端 | AIP AD2.12 | 2024-11-28 | AIP 値そのまま（34R・16L・16R は移設滑走路端（Displaced THR）を採用） |
| 進入 FAF 等（APOLO, ACTOR, CECIL, CREST, UTIBO） | opennav | 不明 | 滑走路延長線からのずれ 0.2°以内を検算済み |
| 磁気偏差 | AIP 表記 | — | −7.9°（W）。画面の方位表示は磁方位 |

注意:
- 2026-09 時点で最新版かは未確認（AIRAC 更新で変わる可能性あり）。
- opennav の CREAM・CLOAK・CAMEL は AIP からの計算値と約 0.9NM ずれており、旧位置と推定して不採用。
- 本データは航法用ではない。

### 2.1 採用する STAR（北風・昼間）

| 流入点 | 方面 | 34L 行き（A：ARLON 終点） | 34R 行き（C：CREAM 終点 / H：CACAO 終点） | 34R ILS Y 行き（K：KAIHO 終点） |
|---|---|---|---|---|
| XAC（OSHIMA） | 西 | OSHIMA 1A | OSHIMA 2C / 2H | OSHIMA 1K |
| AKSEL | 南西 | AKSEL 1A | AKSEL 2C / 2H | AKSEL 1K |
| AROSA | 南 | AROSA 1A | AROSA 2C / 2H | AROSA 1K |
| GODIN | 北 | GODIN 2A | GODIN 1C / 1H | GODIN 2K |
| POLIX | 北東 | POLIX 2A | POLIX 1C / 1H | POLIX 2K |

- MVP では **A（→34L）と C（→34R）** を使う。H と K は第2段階で追加。
- 最終進入: 34L は ARLON → APOLO → 滑走路、34R は CREAM → 最終進入コースへ誘導。

## 3. ゲームの流れ

1. 管制空域の端（流入点）に到着機が出現する。初期状態は STAR 走行中。
2. プレイヤーは速度・方位・高度の指示で順序と間隔を整える。
3. 進入許可を出すと、機体はローカライザーに会合して降下し、着陸する（着陸で +1）。
4. 以下の場合はゲームオーバー。
   - 間隔違反：水平 3NM 未満かつ垂直 1000ft 未満。ただし 34L/34R の平行進入（両機ともローカライザー会合済み）は除外（簡略化。AIP 上も同時平行進入は認可あり）
   - 燃料切れ：出現から一定時間で着陸しない
5. 時間とともに出現間隔が短くなる。

## 4. シミュレーションモデル（簡略）

| 要素 | モデル |
|---|---|
| 座標系 | RJTT の空港基準点（ARP）を原点とする平面近似。x = Δ経度×cos(緯度₀)×60、y = Δ緯度×60（単位 NM）。範囲 ±70NM での誤差は無視できる |
| 時間 | 1 tick = 1 秒（シム時間）。倍速 1×/2×/4× |
| 旋回 | 標準旋回率 3°/s。指示方向（左右）がなければ近い側に旋回 |
| 上昇・降下 | 降下 1,800ft/min、上昇 2,000ft/min（機種によらず一定） |
| 速度 | 加減速 1kt/s。指示速度＝対地速度（風なし）。下限 160kt（最終進入は 140kt） |
| STAR 走行 | 次の経路点へ直行し、到達したら次へ。高度制限が「=」「≤」の点へは、到達時にその高度になるよう降下開始を計算 |
| ILS | 進入許可後、ローカライザー（滑走路方位の延長線）に会合したら、3° パス（約 318ft/NM）に沿って降下 |
| 着陸判定 | 滑走路端から 0.5NM 以内・高度 300ft 以下・機首が滑走路方位 ±15° |
| 機種 | 大型（B777/B787）と中型（A320/B737）の 2 区分。当面は表示のみ（後方乱気流間隔は第3段階） |

## 5. 操作

### 5.1 クリック
機体をタップ → 下部パネルに [HDG] [ALT] [SPD] [DCT（直行）] [APP（進入許可）] [STAR 復帰]。方位はドラッグで指定することもできる。

### 5.2 コマンド（端末風入力欄）

| コマンド | 意味 | 例 |
|---|---|---|
| `H270` / `L270` / `R270` | 方位（磁）。L/R で旋回方向を指定 | `JAL123 H270` |
| `A60` | 高度（百 ft 単位） | `A40` = 4,000ft |
| `S210` | 速度 kt | |
| `D ARLON` | 直行 | |
| `C 34L` | ILS 進入許可 | |
| `STAR` | STAR に復帰 | |

- 1 行に複数指示を並べられる: `ANA45 L250 A50 S190`
- コールサインは前方一致でよい（`JAL1` など）
- 機体を選択中はコールサインを省略できる

## 6. 画面（1980 年代ベクター風）

| 要素 | 仕様 |
|---|---|
| 配色 | 背景 #000、線 #33ff66、弱線 #0f5 の 30%、警告 #ffcc33（緑単色を基本に、警告のみ琥珀色） |
| 燐光残像 | 毎フレーム rgba(0,0,0,0.25) を重ね塗り |
| 発光 | `shadowBlur` 6〜10 |
| 走査線 | 2px 間隔の暗線をオーバーレイ |
| レーダー掃引 | 4 秒周期の回転ビーム。機体の位置表示は掃引時に更新（実機のレーダー更新間隔の雰囲気） |
| 地図 | 滑走路、STAR 線（点線）、経路点（△＋名前）、距離環 10NM、海岸線（第2段階） |
| データブロック | `JAL123` / `080↓050 210`（現在高度↓指示高度 速度）。STAR 名は選択時のみ表示 |
| 音 | WebAudio：違反接近時のビープ、着陸音 |

## 7. 交通生成

| 流入点 | 比率（仮） | 出現高度 | 根拠 |
|---|---|---|---|
| XAC | 35% | 13,000ft | 西日本・韓国・中国方面。EndlessATC 羽田ファイルの記述「到着は南西寄り」を参考にした推定 |
| AKSEL | 25% | 12,000ft | 南西（九州・沖縄）方面 |
| AROSA | 10% | 11,000ft | 南方面 |
| GODIN | 15% | 14,000ft | 北日本方面 |
| POLIX | 15% | FL150 | 北米などの洋上方面 |

- 比率は推定値で、実際の運航統計ではない。後で差し替えられるよう設定値にする。
- 34L と 34R の割り振り：出現時に、その時点で空いている方を選ぶ。プレイヤーが後から変更できる。

## 8. ファイル構成

```
index.html            画面・スタイル
src/main.js           ループ・描画
src/sim.js            機体モデル・STAR 追従・ILS
src/cmd.js            コマンド解析
src/traffic.js        交通生成
data/rjtt_north.json  実データ（抽出スクリプトで生成）
```

## 10. 未確定・リスク

| 項目 | 内容 | 対応 |
|---|---|---|
| データの鮮度 | 2026-09 時点で最新の AIRAC か未確認 | 抽出スクリプトを残し、新 PDF で再生成できるようにする |
