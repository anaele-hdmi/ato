# 低軌道旅行 — アートディレクション v0.1（叩き台）

> 目的: 「Stylized 3D」を言葉ではなく**判定可能なルール**に落とす。M0 はこれを決めずに実装したため、見た目が「写実の劣化版」になった。

---

## 1. M0 の診断（スクリーンショットから）

| 要素 | 現状 | 問題 | 原因 |
|---|---|---|---|
| 地表（昼） | 滑らかなグラデーション＋霞で全体が濁った青緑 | 形（海岸線・大陸）が読めない。写真でも絵でもない | 陰影なしの平塗り＋大気の霞が全面に乗る。色数の上限がない |
| 深海の帯 | sin 関数の縞 | 意味のない模様が出る | 仮実装のノイズ |
| 大気 | 物理寄りの連続グラデーション | 単体では綺麗だが、他の要素と文法が揃っていない | 大気だけ写実、地表は平塗り、と方式が混在 |
| 宇宙船 | 灰色の既定プリミティブ、パネルが黒で見えない | 「仮素材」に見える | 形状・配色の設計がない |
| 星 | 均一な白点が画面全体に多数 | ノイズ。静けさを削る | 数・明るさ・分布の設計がない |
| 構図 | 船が中央、地平線が中央付近 | 絵として組まれていない | カメラ既定位置が技術的都合で決まっている |
| 時間帯 | 昼・薄明・夜で色の管理がばらばら | 「同じ作品」に見えない | 時間帯ごとのパレット（グレーディング）がない |

一言でいうと、**「要素ごとに別の描き方をしていて、全体を束ねる規則がない」**。

---

## 2. 参照作品から抽出できる原則

参照作品の技術的な内部実装は把握していない。以下は画面から観察できる特徴の整理で、推測を含む。

| 原則 | art of rally | Slow Roads | 本作への翻訳 |
|---|---|---|---|
| 形を減らす | 低ポリ、テクスチャほぼなし | 単純な地形とオブジェクト | 地表は大陸・海・氷・雲の**面**だけで語る。細部は描かない |
| 色数を絞る | ステージごとに限られた配色 | 空と霧の色が画面の大半を決める | 時間帯ごとに**5〜7色のパレット**を定義し、それ以外の色を出さない |
| 奥行きは空気で出す | 霧・被写界深度 | 距離フォグが強い | 地平線に向かって**パレット内で**色を寄せる（大気＝フォグ） |
| 光は1灯＋色付きの環境光 | 明快な主光源と影 | 柔らかい光 | 太陽1灯＋「空の色」の環境光。陰影は2〜3段 |
| 構図を先に決める | 固定気味のカメラ | 道路と地平線の配置 | カメラ既定位置を「地平線 1/3、船は端」の絵作りで決める |

## 3. 方向性の候補

| 案 | 見た目 | 強み | 弱み・リスク |
|---|---|---|---|
| **A. 平塗りの段階表現（ポスタリゼーション）** | 陰影と大気を 3〜5 段の色面に量子化。海岸線は明快な形 | 参照作品に最も近い。形が読める。軽い | 段の境目がちらつく（アンチエイリアス設計が要る）。薄明の繊細さが減る |
| **B. 柔らかいグラデーション（霧主体）** | 形は単純、色は滑らかな連続グラデーション。彩度低め | 静けさ・没入感が出やすい。今の大気表現を活かせる | 「のっぺり」「写実の劣化版」に戻りやすい。今の M0 に近い |
| **C. 印刷物調（限られたインク＋粒子）** | 2〜4 インク相当の配色、紙の粒子・版ずれ | 記憶感・物語性が強い。書き出した写真がそのまま印刷物の素材になる | 動く 3D で破綻しないか未検証。好みが分かれる |

**推奨: A を骨格にして、大気と薄明だけ B の滑らかさを残す（A＋B）。C は撮影・現像の出力側のフィルタとして後から検討する。**
- 根拠: A は「形が読める」ことで、地理を観察する体験と相性がよい。大気まで量子化すると、本作で最も美しくなりうる薄明の帯が死ぬ。
- この判断は私の仮説であり、下記 §5 の手順で見比べて決めるのが妥当。

---

## 4. 推奨案（A＋B）の要素別仕様

| 要素 | ルール |
|---|---|
| パレット | 時間帯を「昼 / 薄明 / 夜」の 3 状態＋補間とし、各状態 5〜7 色。全色を `palette.ts` の 1 か所で管理 |
| 地表 | 海・浅海・陸・高緯度の陸・氷の 5 面。陰影（太陽との角度）は **3 段に量子化**。深海の縞は廃止 |
| 雲（M2） | 平らな雲の面、影は 1 段の暗色。雲の輪郭は滑らかな曲線 |
| 大気・薄明 | 連続グラデーションのまま。ただし使える色は各状態のパレット内に限定 |
| 夜 | 背景は完全な黒。都市光（M2）は暖色 1 色の点のみ |
| 星 | 数を現状の 1/4 程度に。明るさは 2〜3 段。地球が画面にある間はさらに減光 |
| 宇宙船 | 面ごとに 1 色、3 色まで（白・灰・パネルの紺）。太陽側だけ明るい 2 段陰影。輪郭が背景に負けないよう、パネルは紺より 1 段明るく |
| 構図 | 外部カメラの既定は、地平線が画面下 1/3〜中央、船は左右どちらかに寄せる。日の出前は太陽の来る方角を画面に入れる |
| ポスト処理 | M0 では入れない。必要なら後からビネット＋粒子の 1 パスのみ |

## 5. 決め方（手戻りを減らす順序）

| 段階 | 内容 | 成果物 |
|---|---|---|
| 1. 参照画を集める | 目標の見た目の静止画（既存作品のスクリーンショット、Midjourney 等で作った参照画）を 6〜10 枚。**昼の真下 / 日の出の地平線 / 夜の地平線 / 船の外観**の 4 場面を揃える | 参照ボード |
| 2. 見比べ用の切替を実装 | `?style=A|B|C` で同じ場面を 3 方式で描画し、4 場面 × 3 方式 = 12 枚を同条件で撮影 | 比較表 1 枚 |
| 3. 1 方式に決める | 下記の判定基準で採点して選ぶ | 決定記録 |
| 4. パレットを固定 | 各時間帯のパレットを確定し、以後の実装はこの範囲で行う | `palette.ts` |

### 判定基準（主観を減らすため）

| 基準 | 測り方 | 合格の目安（仮） |
|---|---|---|
| 形が読めるか | 画面を 200px 幅に縮小して、大陸・地平線・船が判別できるか | 3 つとも判別できる |
| 明暗の構成 | グレースケール化して、明暗が何段に分かれるか | 3〜5 段にまとまっている |
| 色数 | 画面から抽出した主要色の数 | 各時間帯 7 色以内 |
| 静けさ | 画面上の高周波（細かい点・縞）の量 | 星・ノイズが主役にならない |
| 一貫性 | 昼・薄明・夜を並べて同じ作品に見えるか | 3 場面が同じ文法 |

合格の目安の数値は、比較の起点として置いた仮の値。

## 6. 次の作業

1. 段階 2（`?style` 切替）を実装し、12 枚の比較画像を出す。

3. 決定後、M1（軌道・複数カメラ）に進む前に地表・船・星を新パレットで作り直す。

### 残課題（A＋B 初版を見て）

| 課題 | 対応予定 |
|---|---|
| 大陸の内部が単色で間延びする（例: シベリア上空の真下視点） | 雲（M2）で面を分ける。陸の色を乾燥帯など 2 色に分けるかは雲を入れた後に判断 |
| 深海と浅海の差が海岸付近にしか出ない | 意図どおり。単調に見える場合は海流・雲の影で補う |
| 宇宙船の形が単純すぎる | 形状の設計は別途（モジュール配置・ラジエーター等の追加） |
