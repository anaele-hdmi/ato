# one-limb — 一本の線で語るデザイン言語（叩き台 v0.1）

> 出典：「低軌道旅行」のホーム画面アイコン（`examples/limb-icon.svg`）。
> 注意：このアイコンは仮置きとして作られたもので、原則は**作った後から分解して言語化したもの**。
> 原則が再現できるかは未検証（§6）。

---

## 1. 原則（5つ）

| # | 原則 | 内容 | アイコンでの実例 |
|---|---|---|---|
| 1 | **一要素** | 画面に置く図形は1つ。2つ目を足したくなったら、1つ目で表現しきれていない合図 | 弧1本のみ。星・月・宇宙船・文字なし |
| 2 | **主題は画面の外** | 主題の全体を見せず、一部だけ見せる。見えない部分の大きさを見る人に補わせる | 円の中心は画面外（下方）。見えるのは弧だけ |
| 3 | **余白が主役** | 地は無彩色（黒）で面積の9割以上。暗さ・静けさは描かずに余白で表す | 黒地がほぼ全面 |
| 4 | **比率に根拠** | 線の太さ・位置を主題の実際の比率や意味から決める。「なんとなく」の数値を置かない | 線の太さ/半径 ≒ 1.9%。大気の厚み（約100km）/地球半径（6371km）≒ 1.6% に近い（※偶然の一致で、意図した設計ではない） |
| 5 | **グラデーションは時間か方向** | 色の変化は装飾ではなく、時間の経過・光の向き・奥行きのどれかを表すときだけ使う | 下の深い青 → 上の白近く。夜明け前に地平線が明るむ向き |

## 2. 数値テンプレート（正方形キャンバス W×W）

アイコン（512×512）から抜き出した値。出発点であって正解ではない。

| 項目 | 値 | アイコンの実値 |
|---|---|---|
| 地の色 | `#000000`（純黒） | `#000000` |
| 円の中心 | x = 0.5W, y = 1.25W（画面外） | (256, 640) |
| 半径 | 0.82W | 420 |
| 弧の頂点の高さ | 上から 0.43W（中央より少し上） | y = 220 |
| 線の太さ | 0.016W | 8 |
| 色の段数 | 3段（暗 → 中 → 明） | `#0b2b4a` → `#1c6a9a`（45%）→ `#cdeeff` |

## 3. 作り方の手順

1. **主題を1語にする**（例：「夜明け」「大気」「帰還」）。1語にできなければ作らない。
2. **主題の「縁」を探す**：全体ではなく、境界・輪郭・端の一部で主題が分かる箇所を選ぶ（地平線、水平線、影の境、光の縁）。
3. **主題の中心を画面の外に置く**：見せるのは縁の一部だけ。
4. **太さ・位置を根拠のある比率で決める**（§1-4）。根拠がないときは §2 の値を使う。
5. **色は1色相・3段まで**。変化の向きに意味（時間・光・奥行き）を持たせる。
6. **§4 のチェックリストを通す**。
7. **小さいサイズで確認する**（§5）。

---

## 4. チェックリスト

- [ ] 画面上の図形は1つか
- [ ] その図形を消したら何も残らないか（＝唯一の要素か）
- [ ] 主題の全体を描いていないか（一部だけか）
- [ ] 余白が面積の9割以上あるか
- [ ] 線の太さ・位置の数値に理由を言えるか
- [ ] グラデーションは時間・方向・奥行きのどれかを表しているか
- [ ] 色相は1系統か
- [ ] 文字・影・光沢・枠を入れていないか
- [ ] 60px まで縮めても形が分かるか

---

## 5. 既知の弱点と対処

| 弱点 | 内容 | 対処案 |
|---|---|---|
| 小サイズで線が消える | 0.016W の線は 60px 表示で約1px。ホーム画面（約180px表示）では約3pxで成立しているが、通知アイコンなどでは消える可能性 | 小サイズ用に線を 0.03W 前後に太らせた別版を用意 |
| 明るい背景で埋もれる | 周囲の UI が黒でないと「黒い四角」に見える | 地の黒は維持し、外周の角丸はOS任せ |
| 主題を選ぶ | 「縁」を持たない主題（群衆、情報量の多い題材）には不向き | 無理に適用しない |
| 再現性が未確認 | 原則は1例から抽出 | §6 で検証 |

## 6. 検証計画（スキルとして固める前にやること）

同じ原則・同じ数値テンプレートで、別主題を2〜3点試作し、「原則だけで同じ質に届くか」を確かめる。

| 試作 | 主題 | 使う「縁」の例 |
|---|---|---|
| A | 別アプリのアイコン | 例：海 → 水平線の一部 |
| B | ZINE の表紙 | 例：記憶 → 窓枠の影の境 |
| C | 音楽（Suno 等）のジャケット | 例：音 → 波形の1周期の一部 |

判定：
- 成立した → 原則をそのまま採用。
- 成立しなかった → どの原則が足りない／余計だったかを §1 に追記・修正。
